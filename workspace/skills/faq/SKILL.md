# TikTok 多店铺售后 FAQ 知识库服务指南

## 1. 知识来源与双文件规则 (Two-File Policy)

本项目采用**两份确定文件**的租户隔离读取机制，不引入复杂向量检索（RAG），通过清晰的租户路由确保政策答复精准：

1. **品牌通用政策文件**：`knowledge/brand/common.md`
   - 包含 Lumen Home 品牌商品规格（人体工学椅、升降桌、屏幕挂灯、氛围灯）、原厂质保年限、质量问题判定标准与凭证要求、无理由退换标准及工单升级规则。
2. **店铺专属政策文件**：`knowledge/shops/{shop_id}.md`（如 `knowledge/shops/tt-us-west.md`、`knowledge/shops/tt-us-east.md` 或 `knowledge/shops/tt-uk.md`）
   - 包含当前 TikTok 店铺所属仓库、属地物流承诺、运费门槛（如美西/美东 USD、英国 GBP）、法定/店铺退换货周期（如美国 30 天 vs 英国 14 天冷静期）及退货质检仓库地址。

> **严格隔离原则**：
> - 每次服务客户时，仅读取当前店铺绑定的专属文件和品牌通用文件，**绝对禁止跨店铺翻阅或引用其他店铺的政策文件**；
> - 若品牌通用政策与当前店铺政策存在冲突，**以店铺专属政策为最终依据**。

## 2. 查询与解答流程

1. **获取当前店铺上下文**：
   - 调用 `get_ticket_access_context` 工具获取当前会话所绑定的 `shop_id`、`shop_name`、`region`、`currency` 以及对应的 `faq_files` 路径。
2. **读取政策内容**：
   - 使用 `read_file` 工具依次读取通用政策 `knowledge/brand/common.md` 与当前店铺文件 `knowledge/shops/{shop_id}.md`。
3. **精准匹配与回答**：
   - 区分**质量缺陷/运损**与**无理由/个人原因**：
     - 质量缺陷（如电机报错、气压杆故障、运输破损）：按政策提供免费补发配件或包邮退换（提供预付运单），免除买家运费；
     - 个人原因（如尺寸不合适、不喜欢）：核实退货窗口（美西/美东 30 天内，英国 14 天内），且需保持全新未组装原包装齐全。
   - 回答中明确标明当前店铺所属服务标准（如加州仓发货 2-3 日达、英国仓 Royal Mail/DPD 发货）、币种符号（`$` 或 `£`）及退货地址。
4. **追问与信息补充**：
   - 当客户反映商品故障或运损时，主动提示客户提供 TikTok 订单号、包装箱面单及破损部位清晰照片/视频。

## 4. 工单衔接规则 (Ticket Escalation)

当出现以下任一情形时，向客户说明情况并征得同意后，转入创建人工工单流程：
1. 客户核实符合退换货条件，需要人工客服开具 **RMA 编号** 或提供 **Prepaid Return Label 预付面单**；
2. 升降桌电机、主控板损坏需安排补发配件或工程师电话指导；
3. 包裹物流轨迹停滞超过 72 小时需向承运商发起官方丢件调查；
4. 客户要求人工介入处理或对自动化政策回答有异议。

在客户明确确认（如“帮我建单”、“好的”、“需要人工处理”）后，调用 `create_ticket` 工具完成工单创建。
